# Машинне навчання та аналіз даних

Навчальний багатосторінковий вебсайт, присвячений основам машинного навчання, методам аналізу даних і практичним інструментам для роботи з інформацією.

**Довідник дизайн-системи:** https://stttvexx.github.io/lab09_stavnichenko/styleguide.html

## 1. Призначення сайту й тема варіанта

Мета проєкту — ознайомити відвідувачів з історією, основними поняттями, алгоритмами, застосуваннями та інструментами машинного навчання й аналізу даних.

На сайті представлені інформаційні матеріали, порівняння алгоритмів, добірка ресурсів, ілюстрації, відеоматеріал із субтитрами, сторінка зворотного зв'язку та навчальна форма заявки на участь.

**Тема варіанта:** «Машинне навчання та аналіз даних».

## 2. Спосіб запуску

Сайт створено за допомогою HTML і CSS; для перегляду не потрібні встановлення бібліотек, збірка або серверна частина.

1. Завантажити репозиторій або відкрити локальну папку `lab09_stavnichenko` у Visual Studio Code.
2. Установити розширення **Live Server** (якщо його ще немає).
3. Відкрити `index.html` і вибрати **Open with Live Server**.
4. Переглянути сайт у браузері за локальною адресою, яку відкриє Live Server (наприклад, `http://127.0.0.1:5501/index.html`).

Опублікована версія доступна через HTTPS: https://stttvexx.github.io/lab09_stavnichenko/.

## 4. Опис дизайн-системи

Сайт використовує єдину дизайн-систему, описану через CSS-змінні в `css/style.css`.

- **Кольори:** темно-синій основний і текстовий колір, світлі фонові відтінки, жовтий акцент; змінні `--color-primary`, `--color-primary-light`, `--color-primary-soft`, `--color-accent`, `--color-text`, `--color-surface` та інші.
- **Типографіка:** `Segoe UI`, `Roboto`, `Arial`, `sans-serif`; адаптивні заголовки `--font-size-h1`, `--font-size-h2`, `--font-size-h3` із `clamp()`.
- **Шкала відступів:** `--space-1`–`--space-6` зі значеннями 4, 8, 16, 24, 32 і 48 px за базового розміру шрифту 16 px.
- **Заокруглення та тіні:** змінні `--radius-*`, `--shadow-card`, `--shadow-hover`.
- **Повторно використовувані компоненти:** `.btn`, `.btn--primary`, `.card`, `.card.featured`, `.badge`, `.menu`, `.tooltip`, поля форми та `.card-grid`.
- **Адаптивна верстка:** CSS Flexbox, Grid, медіазапити та гнучкі розміри.

Приклади токенів, компонентів, їхніх станів і шаблонів з HTML-фрагментами представлені на сторінці **[Довідник дизайн-системи](https://stttvexx.github.io/lab09_stavnichenko/styleguide.html)**.

## 6. Відомі обмеження

- Проєкт є статичним навчальним сайтом без власної серверної частини та бази даних.
- Форми зворотного зв'язку та заявки на участь використовують сторонній сервіс FormSubmit для надсилання даних на електронну пошту власника сайту. Доставка повідомлень залежить від роботи зовнішнього сервісу та поштового провайдера.
- Для тестування форм рекомендується використовувати демонстраційні дані. Не слід надсилати паролі або конфіденційні документи.
- Результати автоматичних перевірок доступності не гарантують повної доступності: потрібні також ручні перевірки клавіатурою й програмою екранного доступу.
- Відображення системного шрифту Segoe UI залежить від операційної системи; за його відсутності використовуються резервні шрифти.
- Окремі зовнішні посилання й сервіси залежать від доступності сторонніх вебресурсів.
