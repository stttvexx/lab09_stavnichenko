Рівень 1 · Токени

Токени — це змінні CSS, які задають єдині кольори, шрифти, відступи, радіуси та тіні для всього сайту.

Кольори

Primary light --color-primary-light hsl(62 12% 66%)
Primary soft --color-primary-soft hsl(58 29% 76%)
Accent --color-accent hsl(49 68% 68%)
Text --color-text hsl(214 93% 23%)
Text muted --color-text-muted hsl(213 55% 35%)

Border --color-border #e3e7ec
On dark --color-on-dark #ffffff
Tooltip --color-tooltip #222222
Header overlay --color-header-overlay-top --color-header-overlay-bottom

Темно-синій колір використовується для заголовків, кнопок і навігації. Світлі кольори застосовуються для фону блоків, а жовтий — для акцентних елементів.

Рівень 2 · Компоненти

Компоненти — це повторно використовувані елементи сайту. Вони мають спільне оформлення, визначене в css/style.css.

Кнопка (.btn, .btn--primary)

Призначення: виконання дії або перехід до іншої сторінки.

Основна Звичайна

HTML-код

<a class="btn btn--primary" href="about.html">Основна</a>
<a class="btn" href="gallery.html">Звичайна</a>
<button class="btn" type="button" disabled>Вимкнена</button>

Різновиди й стани: основна та звичайна кнопки; наведення :hover, фокус :focus-visible, вимкнений стан disabled.

Доступність: посилання використовуються для переходів, а кнопки — для дій. Контур фокуса має залишатися видимим.

Коли не застосовувати: не використовувати кнопки замість заголовків, підписів або звичайного тексту. Для пунктів меню використовуються посилання.

Призначення: групування тематично пов'язаної інформації.

Переглянути ресурси

Виділена картка

Картка з темним фоном для виділення важливої інформації.

HTML-код

<article class="card">
    <h3>Основи машинного навчання</h3>
    <p>Опис матеріалу.</p>
    <a href="about.html">Детальніше</a>
</article>

<article class="card">
    <span class="badge">Нове</span>
    <h3>Аналіз даних</h3>
    <p>Опис матеріалу.</p>
</article>

<article class="card featured">
    <h3>Виділена картка</h3>
    <p>Важлива інформація.</p>
</article>

Різновиди й стани: звичайна картка, картка з міткою та виділена картка. При наведенні з'являється додаткова тінь.

Доступність: інформація повинна мати логічну структуру, змістовний заголовок і зрозумілі посилання.

Коли не застосовувати: картки не використовуються для одиночної кнопки або звичайного абзацу, якому не потрібне окреме групування.

Значок (.badge)

Нове

Новий матеріал

Значок розташовується у верхньому правому куті картки.

HTML-код

<article class="card">
    <span class="badge">Нове</span>
    <h3>Новий матеріал</h3>
    <p>Опис матеріалу.</p>
</article>

Значок використовує position: absolute, а картка — position: relative.

Доступність: значення значка передається текстом, а не лише кольором.

Цитата (blockquote)

Якісні дані є важливою основою ефективного машинного навчання.

HTML-код

<blockquote>
    Якісні дані є важливою основою
    ефективного машинного навчання.
</blockquote>

Для оформлення цитати застосовується ліва межа та курсивний текст.

Навігаційне меню (.menu)

  • Головна

HTML-код

<nav aria-label="Основна навігація">
    <ul class="menu">
        <li><a href="index.html">Головна</a></li>
        <li><a href="about.html">Про ML</a></li>
        <li><a href="gallery.html">Галерея</a></li>
    </ul>
</nav>

Меню створено за допомогою Flexbox. На вузьких екранах посилання переносяться завдяки flex-wrap: wrap.

Поле форми (input, select, textarea)

Призначення: введення інформації користувачем.

HTML-код

<label for="email">Електронна пошта</label>
<input type="email" id="email" name="email" required>

<label for="subject">Тема звернення</label>
<select id="subject" name="subject">
    <option value="question">Запитання</option>
    <option value="suggestion">Пропозиція</option>
</select>

<label for="message">Повідомлення</label>
<textarea id="message" name="message"></textarea>

Різновиди й стани: текстове поле, електронна пошта, список, текстова область, прапорець. Стани: звичайний, фокус, помилка, вимкнений.

Доступність: кожне поле має підпис <label>, атрибут for якого відповідає id поля. Обов'язкові поля мають атрибут required.

Коли не застосовувати: поля форми не використовуються для відображення статичного тексту.

Підказка (.tooltip)

Додаткова інформація про компонент.

HTML-код

<div class="tooltip-container">
    <button type="button"
            class="btn"
            aria-describedby="hint">
        Підказка
    </button>

    <span id="hint"
          class="tooltip"
          role="tooltip">
        Додаткова інформація
    </span>
</div>

Підказка відображається при наведенні або фокусі всередині контейнера.
